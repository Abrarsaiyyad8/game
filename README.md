A browser Game theme on zombies_vs_humans TIC TAC TOE 
This project demonstrates how to deploy a browser game created by (HTML/CSS/JavaScript) using a real-world DevOps lifecycle.
with fully automated cloud infrastructure, CI/CD, containerization, monitoring and Game analytics.


🎯 Project Goal 
* Infrastructure as code     - Terraform
* CI/CD pipeline             - Jenkins
* Containerized Deployment   - Docker
* Cloud Compute              - EC2
* NoSQL Database             - DynamoDB
* Container Registry         - ECR
* Monitoring & Observability - Prometheus + Grafana
